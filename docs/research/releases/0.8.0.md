# Lens for arXiv 0.8.0

## Current probability workflows

- **Digest** adds opt-in desktop Chrome notifications for new unrated papers with genuine match probabilities strictly above 0.8 in the latest local batch. Chrome alarms check every 30 minutes while Chrome and the companion are running. Checks cover all subjects; the subject selector filters only the view. No new qualifying papers means silence. Paper IDs are acknowledged only after successful Chrome notification creation; denied or failed notifications stay pending. Fetching new arXiv metadata remains a separate action.
- **Your 80%+ reality check** records the first genuine forecast before feedback and compares forecasts of at least 0.8 with later ratings. It shows liked X/Y, observed percentage, mean forecast, and a caution below ten observations. Existing Library ratings are never backfilled. This is selected-feedback evidence, not population calibration across all arXiv papers.
- **Sharpen** offers up to six unrated papers, combining binary prediction entropy, embedding diversity, and interest relevance within the model shortlist. Internal uncertainty becomes available with TabPFN access and six ratings, including at least two of each kind. Earlier profiles, absent access, or inference failure receive diverse starter papers. Feedback invalidates the queue. Early percentages stay hidden; the normal 30-rating / three-of-each match threshold is unchanged.
- **Top citations** now shows scoring progress, unavailable coverage, and the expected remaining relevance of distinct resolved, scored, unrated bibliography papers. The total is the sum of their probabilities; rating a paper removes it immediately. **About N more references you may like** is a rounded expectation, not a guarantee or a count of every bibliography entry.

Sharpen is an uncertainty-and-diversity heuristic, not formal value of information. This release does not establish faster cold-start learning. The frozen benchmark claims are unchanged. The revised showcase now illustrates these features using staged scores and feedback; it is not a recording of live model inference.

## Local data and access

`insights.json` in the selected profile root stores prospective forecasts, digest opt-in, and offered/delivered paper IDs with mode `0600`. Profiles remain ignored by Git and excluded from extension packaging. Chrome adds `alarms` and `notifications` permissions for the opt-in local alerts. Provider token verification and external credential storage are unchanged; there is no hosted notification service. [Privacy details](../../PRIVACY.md).

## Validation and limits

Isolated-profile browser checks used real local TabPFN-3.5 Fast on Apple Silicon (MPS), with the public curated persona. The ready profile advanced from 43 to 46 ratings and the early profile from six to eight. The reality check changed from 1/2 to 2/3 after feedback; Sharpen refreshed after the seventh rating, excluded the rated paper, and displayed no early percentage. The citation fixture had five scored references and one unavailable reference; its expected remaining total changed from 2.1 to 1.1 immediately after a rating. Desktop (1280px) and narrow (390px) views were inspected without a new visual defect.

Automated checks cover prospective history/no backfill, threshold boundaries, queue selection and invalidation, deduplication and remaining expectation, and service-worker permission denial, successful creation before acknowledgement, check coalescing, offline alarms, and authentication failures. See [packaging verification](../../VERIFICATION.md) for the final suite counts and ZIP checks.

Native Chrome/OS notification banners and live arXiv integration were not newly verified in this pass; the browser checks used the in-app browser and local fixture. Availability of match estimates still depends on configured model access and a running companion. Automatic reference resolution can select an incorrect version; inspect the title/source and use the manual-link fallback when needed.

## Update

Restart the Python companion, reload Lens in `chrome://extensions`, and refresh open arXiv tabs. Allow Chrome/OS notifications if you enable Digest. [Setup guide](../../GETTING_STARTED.md) · [Extension guide](../../../lens/extension/README.md).
