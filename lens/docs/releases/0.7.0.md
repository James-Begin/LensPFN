# Lens for arXiv 0.7.0

## What changed

- Animated first-run setup guides users through companion connection, reading interests, optional TabPFN access, and the rating requirements for personalized matches. Existing settings are reused, setup completion is remembered, and preferences can reopen the guide.
- After citation scoring completes, a dismissible popup recommends up to five highest-matched cited papers, with Interested and Open in Lens actions.
- HTML citation previews show the cited paper’s metadata and match-loading state. References without explicit arXiv links resolve automatically by DOI or title when an arXiv version is available.
- Citation scoring is prefetched on page open, shares metadata and score caches with hover previews, and refreshes after five rating changes. Shortlist updates use restrained movement and staggered arrivals.
- Reduced-motion preferences disable spatial transitions.

## Access and local data

New TabPFN credentials are verified with Prior Labs before replacing access, saved atomically outside the project with mode 0600, and cleared from the form. Provider tokens are not stored in extension storage or returned by the companion. The setup API requires companion authentication and is not exposed to arXiv content scripts. Local profiles, credentials, caches and virtual environments are excluded from source and the ZIP.

## Validation

40 Python tests and 30 JavaScript tests pass. Chrome checks covered setup completion on an isolated profile, pairing and token validation errors, saving interests, optional-access skip, completion persistence, revisiting setup, keyboard focus, reduced motion, and a 390px viewport. Citation recommendations were verified on the localhost HTML fixture at desktop and 390px sizes. Existing provider access was verified read-only; setup tests did not alter the live profile or credentials. Live arXiv DOM testing remains pending.

## Update

Reload Lens in `chrome://extensions`, then refresh open arXiv HTML tabs. Preview the guide at `http://127.0.0.1:8765/?setup=1` while the companion is running. New users should follow `extension/README.md`.
